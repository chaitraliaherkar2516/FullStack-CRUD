# Product Management System

A web-based project management system developed using React and Django REST Framework.

## Features

- Add Product
- Edit Product
- Delete Product
- Search Product
- Category Filter
- Price Sorting
- Product Details
- Product Summary
- Category Summary
- CSV Export
- Price Validation

## Technologies Used

- React.js
- Django
- Django REST Framework
- Axios
- HTML
- CSS
- JavaScript
- SQLite

## Project Type

Internship project
